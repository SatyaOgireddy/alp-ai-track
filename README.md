# ALP AI Literacy and Agentic AI Programme

## Week 1 Project – Gemini Teaching Assistant

### Overview

This project was developed as part of the ALP AI Literacy Programme.

The application uses the Google Gemini API to generate educational content automatically.

### Features

- Generate 5 Multiple Choice Questions (MCQs)
- Generate 2 Short Answer Questions
- Generate 1 Programming Question
- Generate Answer Key
- User-defined topic input

### Technologies Used

- Python
- Google Gemini API
- Cursor AI
- Git
- GitHub
